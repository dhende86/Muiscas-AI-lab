# Muiscas AI Lab

Welcome to the Muiscas AI Lab repository!

This repository contains the source code for the Muiscas AI Lab's modernized presence, specifically focusing on the new website front-end.

## Directory Structure

- **[`website/`](./website/)**: The main React-based front-end application built with Vite and TailwindCSS. It features a highly interactive and futuristic UI design.

## Overview

The goal of this repository is to organize and host the digital assets and web projects related to Muiscas AI Lab.

For detailed instructions on how to run, edit, and deploy the website, please refer to the [Website README](./website/README.md).
